Web Development

Useful Tools and Resources

Logan Edwards

Updated 09/06/2026

The Odin Project

An extremely useful site that helped kickstart my web development skills.

The lessons are well-thought out and teach you how to find answers for yourself. Many online development resources I have found just feel like they're working through a checklist (like w3schools).

It also teaches you how to use the actual tools you would in the field, like git, github, vscode, and more.

The Modern JavaScript Tutorial

Detailed explanations with examples that teach you what to do and why you do it.

MDN Web Docs

Mozilla did a fantastic job putting this one together. It has years of documentation on CSS, HTML, and JavaScript.
