Useful Tools and Resources

Logan Edwards

OverTheWire: Wargames

A really cool site that teaches you how to use linux and reverse engineer systems. You interact with the wargames via ssh, which I find fun.

pwn.college

Maintained by a team of hackers at Arizona State University and is suprisingly fun and approachable. It seperates different lessons into "dojos" and lets you earn "belts" to show off your knowledge.

You can interact with the lessons in various ways, including a dedicated web terminal, web vscode, ssh, and virtual machine. They even allow you to save files to use between lessons.
